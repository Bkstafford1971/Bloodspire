TURN 28 BUG FIX & PLAYTEST REMINDER - JULY 30, 2026

Honored Managers,

During the processing of Turn 28, an unexpected bug occurred where certain warriors were incorrectly marked as deceased prior to the turn processing. Consequently, these warriors did not participate in their scheduled bouts and remained marked as dead.

What Caused This Issue

This bug was inadvertently created by a fix put in place to address an earlier exploit where a stale file upload resurrected slain gladiators. Because logs are automatically purged after three turns, tracking down the root cause of an issue that went unreported for five turns required a significant portion of a day to isolate and fix.

Action Required for Affected Warriors

If you have a warrior still showing as dead who should not be, please let me know right away and DO NOT create a replacement warrior. I can manually reactivate any warrior that was incorrectly marked as deceased on my end.

A Friendly Playtest Reminder

I would like to gently reiterate that we are currently running an active playtest arena. Once this playtest phase concludes, all warrior stats, win/loss records, kill counts, and arena standings will be completely wiped. None of these records will be preserved for production.

Because all of this test data will be erased anyway, individual records right now carry no long-term weight. What does matter is identifying and resolving bugs so we can bring Bloodspire Arena to full production smoothly. If you ever notice an anomaly or bug, please report it immediately, even if it happens to be something your team temporarily benefits from.

Thank you all again for sticking with me throughout this process, for your understanding, and for your help in making this game the best it can be!

ENGINE UPDATES, SKILL FIXES & CLIENT V3.3 - JULY 19, 2026

Honored Managers,

Several updates have been made to the game engine and to the client.

Engine & Combat Updates

  • Skills Analysis: Performed an analysis and found 5-6 secondary skills that were not wired in correctly or were partially working. Disarm, Sweep, Charge, and Strike were all non-functional. The framework was there for them, but nothing was hooked into the combat engine. These have been corrected.
  • Throw Accuracy: This skill was partially working. The skills learned were helping to increase the damage from the throw, but did not increase the accuracy as intended. This is now fixed.
  • Multiplier Adjustments: Lunge, Slash, and Bash were using an incorrect multiplier (x3 instead of x4). This has been corrected.
  • Brawl Logic: Brawl was only effective for helping to get off the ground when knocked down. New logic now helps with Martial Combat tactics more, as it should.
  • Luck: Luck has been fixed. Previously it was a permanent bonus on every roll; now it is truly a luck stat and can fire for different rolls randomly. This makes luck feel more natural and not just a huge boost to every roll if your luck score was high or a death sentence if it was low.
  • HP Formula: Modified the HP Formula to increase HP for all warriors. As skills become more prominent, there are several stacking bonuses applied. Due to this, damage rolls were getting higher, as they should with skill learns. Too many weaker races and builds were getting "one-shotted" in a fight. This should be gone now and we should actually see some 2-3 minute fights again. (Note: A heavy hitter build against a frail speed build could still result in a one-shot win or kill, but should be less common).

Client Update (v3.3)

  • Challenge Tab: Added sortable headers so you can sort by any column to find a foe. Added the recognition score and warrior recognition to the challenge table.
  • Scouting: Scouting is no longer a real-time event. You will now need to set the scouts you want, upload, and wait. You will get your scouting report after the turn processes. You also have the ability to save the scouting reports. They will save to your saves folder in a folder called "scouting".
  • Scouting Reports: Scouting now includes the fight narrative of the warrior you sent your scout to see. It will still show all the other information that it already had, just added info for you to peruse.
  • Scout Flavor Text: Added a flavor line to the fight text for scouting letting the manager know that a scout is there to see that fight. It does not specify which warrior they are scouting, but does tell you they are there. If there is one single manager scouting a warrior, it will show the manager that sent the scout to watch. If multiple managers are scouting those warriors, the line will state that there is more than 1 scout in attendance, but will not let you know what managers sent them.
  • Refresh Game Data: There is a new "Refresh Game Data" option in the preferences menu. Using this will send a new json file to the user, updating any changes to trigger wording, weapon names, or skill names. This is needed so the client can render the proper items in the dropdowns.

Note: You will DEFINITELY need Client version 3.3 before the next turn runs. Make sure that you update prior to Tuesday evening. I would probably suggest doing a new upload with the new version before the turn runs, just to make sure there are no stale records anywhere.

Thanks for your continued testing.

ARENA UPDATE: BLOOD CHALLENGE SYSTEM OVERHAUL - JULY 7, 2026

Honored Managers,

I have updated the Blood Challenge system to better reflect the risks and rewards of challenging opponents in the arena. These changes are designed to encourage fair competition, reward underdog spirit, and ensure that those who repeatedly use their status to crush weaker opponents face lasting consequences.

The Crowd is Watching

The audience in the arena is now much more reactive during Blood Challenges. Their support for an underdog is not just flavor text; it is now mechanically aligned with the fight’s outcome. You will notice the crowd’s influence more clearly in fight logs, as the narrative will accurately reflect whether the crowd helped shift the momentum of the battle.

Crowd influence goes well beyond simple support. During a challenge, spectators may begin throwing objects at the "bully" to provide distraction penalties to their attack, parry, dodge, and initiative rolls. While these distractions are limited and do not cause physical damage, they can cause a warrior to swing and miss on an attack or misread a parry attempt.

Support for the Underdog

Challengers who take on a significantly stronger opponent (a Blood Challenge in the Underdog zone) now have a much better chance of survival. The crowd is firmly behind these brave souls, providing a meaningful bonus to their chance of securing mercy before a fatal blow is struck. This ensures that a desperate underdog has a realistic path to survive and fight another day, even if they aren't able to claim a direct victory.

Consequences for Excessive Elbow Dropping

I have refined how the arena treats established warriors who seek out weak opponents. Previously, the penalties were easily gamed, but now the consequences are persistent:

  • Public Shaming: New flavor text has been added to the newsletter, explicitly calling out the egregious Elbow Drop offenders (Bullies) to the public.
  • Popularity Hits: Bullies will suffer a significant, long-term drop in popularity. This penalty follows them into every future fight, making it harder for them to request mercy from the crowd when they find themselves in trouble.
  • Reputation Stability: Recognition will no longer be the primary target for bullying penalties, preventing top-tier warriors from artificially "tanking" their tier to secure easier matchups.
  • Champion-Specific Penalties: Being the champion brings greater scrutiny. Champion "elbow drop" Blood Challenges are treated with extra harshness, and you will gain a permanent bullying mark for each offense. This is where the potential 65% chance of losing a title due to elbow dropping comes into play. While having your title stripped is significant, it does not mean you are unable to regain it later.
  • Standard Challenges: For standard, non-champion Blood Challenges, the crowd interference is still prominent, and the public shaming in the newsletter still occurs. However, the bully tally is not counted against you, though you will still lose popularity points for repeatedly elbow dropping, which could affect your ability to get mercy in future fights.

These adjustments ensure that Blood Challenges are a strategic risk-versus-reward mechanic rather than a tool for casual dominance. I want players to play the game the way they want, but just like in life, there should be a consequence to every action and rewards for underdogs. Besides, everyone loves an underdog story, right? This is in no way meant to call out anyone’s preferred style of play. We need villians and hero types in every game. I think it just adds an extra element to the game to try to make it more immersive and fun. Good luck to all challengers in the arena.

BALANCE MODIFICATIONS & PROVING GROUNDS - JUNE 28, 2026

Honored Managers,

New client version 3.0.0 is now available. Please head over to the downloads section to update your version. Below are some of the enhancements and fixes included in the new version

Racial Balancing

Six races received targeted balance corrections based on a comprehensive win-rate audit. Dwarf was significantly overperforming; Halfling and Goblin were significantly underperforming.

Weapon Adjustments

Adjustments made to a few weapons. Longsword and Scimitar were given a slight base damage bump to be consistent with other weapons of the same weight. Large weapons in the 6.0 - 7.0 weight range were bumped to 3.5 APM average. These include the Great Sword, Great Axe and Battle Flail to name a few.

Armor Dexterity Penalties

Armor dexterity penalties rebalanced. Wearing armor that is too heavy for your build is penalized more naturally against Init, Dodge and Parry rolls. These will also affect your endurance scores more. Over armoring will have a drawback now.

New Features

  • Proving Grounds tab: This is a managers ledger for important stats to track. This will track a managers record versus other managers, what the cumulative record for each race is, what the record for race vs race is, and a weapon performance chart that tracks the effectiveness of each weapon and what race and warrior wields them the best.
  • The Crypts: Renamed the Archives tab to The Crypts to be more immersive with the game theme. No changes were made to the tab contents here.
  • Challenge Mode Strategy Option: This will allow a warrior to have a completely separate strategy loadout for challenges if they choose. No longer just a single trigger option, you can set up a completely new strategy for a challenge to a warrior. If the challenge is successful and the Challenge Mode option is selected, then you will use that strategy for the fight. If the challenge is unsuccessful, your gladiator will default to the standard strategy. If the checkbox is selected, but a challenge is not made, the standard strategy will be used. This new "alternate" strategy will only be used if you initiate a successful challenge or Blood challenge and have the option selected.
  • Fight Headers: Modified the fight headers to increase the font size to make the matchup names stand out a little more, and added the current popularity score into the warrior description.

Minor Bugs and Fixes

  • Tab Focus: Fixed tab focus issues. Now when you switch warriors, you will stay on the current tab you were on. For example, if you are on the Fights tab, and switch to a new warrior, you will be taken to the fights tab for the warrior you switched to.
  • Activity Level: Fixed an Activity level bug where you were not allowed to set an activity level of 0.
  • Ranking Tiers: Updated the ranking tiers and removed the 5 fight requirement needed to leave the recruit tier. Now recruits are set to 10 recognition or less. Along with this, updated the challenge range to be the current tier that your warrior is in and one tier above. Hoping this will balance the random matchups more.
  • Champion Challenges: Champion can be challenged only by warriors in the top 2 active tiers, or by anyone on a Blood Challenge.

Coming Soon

New peasant names. Please submit your peasant names that you want. Remember, as a thank you from me, I am allowing the playtesters to rename the peasants, so each of you will get at least 1 peasant to rename.

STATE OF THE ARENA & UPDATES - JUNE 5, 2026

Honored Managers,

⚠️ ATTENTION: You will need to download and install client version 2.7.4 before downloading the next turn!

The first 4 turns seem to have run fairly smoothly. There have been some minor issues along the way that I have been working on addressing. The most concerning has been the corruption of the files for a couple of Bloodied Entrails teams. I believe that I have that cleaned up and I think it was a version issue that popped up. Along with that, I have addressed a few other minor issues as well as adding a few enhancements.

Resolved Issues & Logic Tweaks

  • Trigger Positioning & Logic: Fixed an issue where if a warrior went from medium damage to heavy damage, but only had a medium damage trigger, it was defaulting back to their always strategy. Now, the logic will read it as medium or heavier and stay on that trigger if there is not a Heavy damage trigger set. Also, this is a good time to remind you that trigger positioning is very important in how they are used.
  • Tab Navigation Memory: Resolved a problem where if you had multiple replacements on a turn and switched between tabs while working with a replacement before saving it, you would lose all the changes to that replacement. Now, you can go as far as to log off and come back later and your previous changes are remembered.
  • Turn Challenge Clears: Corrected an oversight where we were not clearing challenges after each turn. Teams or managers on "auto-pilot" were issuing the same challenges each turn. This is remedied with a simple challenge removal after the turn is processed.

New Enhancements

  • Re-download Newsletter: Added a Re-download newsletter feature in the Actions menu. If you fail to receive a newsletter, you can simply use that feature and it will download the latest newsletter from the server (effective after turn 5 runs).
  • Blood Challenge Windows: Modified the Blood Challenge logic. Now, the 3 turn BC window will last even if a manager tries to sit a team out. The 3 turns are counted when the killer fights. No more trying to avoid retribution; the longer you sit out, the more powerful the opponent gets.
  • Race Traits & Combat Flavor: Added a few more individual race special traits. We have also modified some narrative lines to be more grammatically correct, specifically around martial combat. If you kick an opponent, it properly registers the "hit" line as a kick instead of an open hand attack or a generic line.
  • Claw Attacks: Added new flavor around claw attacks from Lizardfolk and Tabaxi for Martial Combat. These made sense due to the nature of the race.
  • Knockdown Formula Tweak: Modified Knockdown logic so we don't have as many knockdowns in fights. Also added in some logic to reward the knockdown for the sweep skill.
  • Newsletter Text Fixes: Corrected the newsletter fight descriptions to show the proper verbiage for a challenge, Blood Challenge, Monster fight, and random matchup.
  • Several other minor enhancements have been made as well.

Looking to the Future

My next big project for this will be to incorporate a tournament engine. I have been working through the planning stages at this point and I think I have a good outline of how I would want it to look.

The prize pool I am thinking of at this time is as follows:

  • Removal of 3 levels of Permanent injuries
  • 3 points permanently added to size
  • Auto max 1 skill to 9
  • Change and select a new Favorite weapon
  • +10 permanent HP increase

Winner of each tier of the tournament would have a choice of one of these prizes. Again, this is still in the planning stages and a ways off for now.
