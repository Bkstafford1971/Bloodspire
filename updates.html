System Updates & Bug Fixes

Latest stability improvements, gameplay adjustments, and engine fixes.

v2.1.0 Changelog
May 10, 2026

Naming Collision & Server Logic Fixes

  • Duplicate Name Collision Resolved Fixed an issue where teams or warriors sharing names caused logic failures. Previously, this caused some warriors to miss fights or incorrectly match against normal players instead of monsters.
  • Unique ID Implementation Added Unique ID strings to all teams and warriors, implementing backend indices for precise identification regardless of shared names.
  • Admin Team Deletion Implemented backend functionality allowing admins to remove teams at manager request, triggering an API call to clear stale data from the client.
  • Locked Text Field Rendering Resolved a client-side bug in the "Create New Team" and "Create Replacement Warrior" screens where name fields appeared uneditable until the window was minimized and restored.
  • "Run Next Turn" Upload Logic Fixed a bug where uploading with the "Run Next Turn" box unchecked would lock the team out of the turn list. The server now allows re-uploads to correctly register the team once the checkbox is selected.

Next Planned Updates

  • Stat Formula Reworks Adjusting Endurance and HP formulas to address combat length issues (currently too many fights exceeding 10 minutes).
  • Weapon Damage Scaling Increasing damage for small finesse and medium-sized weapons to make them more competitive.
  • Critical System & Narratives Introducing Critical Hits and Critical Parry/Dodge formulas along with associated immersive narrative lines.
  • Combat Consistency Tweaking the random disarm frequency and refining the "Arena Happenings" report to reduce repetitive statements.
  • Newsletter Enhancements Updating the "Top Managers" section for a more natural visual flow.

  • Blood Challenge Logic Updated triggers and scaling backend for Blood Challenges.
