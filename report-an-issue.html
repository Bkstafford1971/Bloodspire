Report an Issue

Help improve the simulation by reporting bugs, balance issues, or mechanical glitches encountered during playtesting.

Requirement: You will need a GitHub account to submit a report. This allows me to reply directly to you if I need more information or once the fix is live.

How to Report:

  • Describe exactly what you were doing when the issue occurred.
  • Include any specific error messages or unexpected combat outcomes.
  • Mention the browser or device you are using.
